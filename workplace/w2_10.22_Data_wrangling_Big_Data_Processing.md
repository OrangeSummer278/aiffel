# 모두마켓 월간 로그 — 도구 선택 보고서

## 1. 데이터 개요

- 파일: web_logs.csv
- 크기: 97.8 MB, 50,000 행
- 주요 컬럼: ts / user_id / page / device / status_code / response_ms / bytes_sent

## 2. 측정 결과

| 방식           | 소요 시간 | 메모리 피크 |
| -------------- | --------- | ----------- |
| pandas + dtype | 0.77초    | 42.1MB      |
| pandas chunked | 0.84초    | 28.9MB      |
| Polars lazy    | 0.95초    | 119.5MB     |

## 3. 분석 결과 요약

- 페이지별 평균 응답 시간 최고: cart (160.27ms)
- 디바이스 점유율: mobile 69.9%, desktop 25.1%, tablet 4.9%
- 에러 1위 페이지: home (42,898건)

## 4. 도구 선택 정당화 (한 단락)

이 분석에는 **pandas chunked** 을 선택했습니다. 이유는
(1) 측정 결과 메모리 피크가 가장 작으며, (2) 팀 환경상 pandas를 주로 사용하고, (3) 데이터의 크기, 처리 시간이 polars를 써야할 만큼 크지 않기 때문입니다.

- 데이터 크기가 100만 행까지 늘어나면 Polars(eager / lazy) 로 전환을 고려.
- 시각화·검증은 D+008에서 Plotly을 활용해 진행.
