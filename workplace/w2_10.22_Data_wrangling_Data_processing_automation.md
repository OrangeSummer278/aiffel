# 모두마켓 이번 달 주문 데이터 — 전처리 자동화 리포트

## 1. 데이터 개요

- 입력 행 수: 1,500행 → 출력 행 수: 1,404행
- 제거된 행: 96행 (6.4%)
- 컬럼 수: 22개 → 40개 (신규 18개)

## 2. 행 정제 (무엇을 걸러냈나)

- 결측 제거: `amount`, `customer_age`가 비어 있는 행
- 이상치 제거: 나이 범위(0 < 나이 < 120) 밖의 값(999세, -3세 등), 수량 20 초과 주문(80개)
- 제거 비율 6.4%로, 분석에 쓸 데이터의 대부분(93.6%)은 유지됨

## 3. 컬럼별 결측 비율 (상위 5개)

| 컬럼                | 정제 전     | 정제 후 |
| ------------------- | ----------- | ------- |
| amount              | 60건 (4.0%) | 0건     |
| grade_apply         | 60건 (4.0%) | 0건     |
| grade_vec           | 60건 (4.0%) | 0건     |
| age_next_year_apply | 30건 (2.0%) | 0건     |
| customer_age        | 30건 (2.0%) | 0건     |

- `grade_apply`, `grade_vec`의 결측 60건은 `amount` 결측에서 그대로 이어진 것 (금액이 없으면 등급도 없음)
- 정제 후 남은 결측은 `membership_score` 1건(약 0.07%)뿐

## 4. 파생·인코딩 컬럼

- 새로 만들어진 컬럼: 18개
- 주요 내용: 등급(grade), 내년 나이, 멤버십 점수, 채널·카테고리 원-핫 인코딩 등

## 5. 자료형 분포 (정제 후)

- int64: 17개 (원-핫 인코딩 열, 수량 등)
- float64: 12개 (금액, 가격, 나이 등)
- object(문자열): 11개 (원본 범주 열, 등급 라벨 등)
