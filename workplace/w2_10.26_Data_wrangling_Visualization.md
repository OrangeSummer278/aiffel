# 모두마켓 웹 접속 로그 — EDA & 시각화 보고서

## 1. 데이터 개요

- 행/열: (2502행, 7열)
- 주요 컬럼: log_id, session_id, response_time_ms, request_path, device, hour, is_error

## 2. 결측 진단 (missingno)

- `response_time_ms` 결측 비율: 4.8 %
- 결측 패턴: response_time_ms 결측이 새벽에 집중, 나머지 시간대는 낮음
- 의심 가설: 새벽 2~4시 서버 점검·배치 작업 등으로 응답시간 측정이 누락되었을 가능성

## 3. 정제와 검증 (전·후 분포 비교)

- 적용한 정제: 중복 제거 / device 표기 통일 / hour 이상치 / response_time_ms 결측 대체 / 극단치 클리핑
- KDE 비교 결과: 중앙값·범위는 정제 전후 거의 동일, 다만 요청 경로별 중앙값으로 대체로 첨도가 높아짐
- device distinct: 5 → 2 (정상)

## 4. 탐색에서 도출한 새 질문

- 자정 직후(0~1시) 에러 건수가 다른 시간대보다 다소 많아 보이나, 전체 에러율이 낮아 우연한 변동일 가능성이 있음
- 응답시간 결측은 새벽 2~4시에 뚜렷하게 집중되므로,  에러 증가와 이어지는 현상인지, 별개의 측정 누락인지 확인 필요
